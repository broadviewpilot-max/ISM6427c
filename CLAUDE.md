# Standing instructions

## Multi-agent research apps
When asked for a multi-agent research app, use the playbook in the agents-21 GitHub repo (`docs/PLAYBOOK-multi-agent-build.md`). Read the playbook itself at the start of the build. Core rules:

1. Resolve conflicts first, with labeled decisions.
2. Use evidence-bound expert agents.
3. Compute scores in code, not in the model.
4. Make the app unable to send anything.
5. Keep keys out of the repo.
6. Give click-by-click instructions.
